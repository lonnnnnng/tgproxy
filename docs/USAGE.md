# 使用指南

> 面向用户的操作手册。服务已部署在局域网服务器 192.168.1.2。

## 现在要做的（首次启用，约 2 分钟）

### 第 1 步：登录 Telegram（无需填 API 凭证）

1. 浏览器打开 **http://192.168.1.2:8080**
2. 填手机号（国际格式如 `+8613800138000`）→ 点「**发送验证码**」
3. Telegram 官方账号会发来验证码（如果验证码发到了你自己的其他 Telegram 客户端，去那里看）
4. 填验证码 → 点「**登录**」；开启了两步验证的话再填 2FA 密码，再点一次「登录」
5. 顶部状态变成「Telegram 已连接」即可

> API 凭证（api_id/api_hash）已内置官方桌面端的公共标识，正常情况**无需填写**。
> 只有遇到公共凭证被限流（FLOOD_WAIT）时才需要去 https://my.telegram.org 申请自己的，
> 填入页面「Telegram API 凭证」卡片覆盖默认值。
> 登录凭证保存在服务器 `~/tgproxy/data/config.json`，之后重启自动重连，无需再登。

### 第 2 步：添加频道、扫描、建库

在管理页面「频道管理」卡片：

1. 添加频道：支持 `@频道名`、`https://t.me/xxx` 链接、数字 ID，可添加多个（A/B/C…源统一入口）
2. 点「**扫描全部频道**」——后台遍历频道历史，收集所有视频文件（右下日志可见进度）
3. 点「**重建媒体树**」——自动归类生成 `剧名/Season 01/剧名 SxxEyy.strm`
   - **同名不同集跨频道自动归并**：比如频道 A 的《庆余年》E01-E02 和频道 C 的 E03 会合成一部剧
   - 没有集号的文件（电影类）独立成组
4. 以后频道里有新内容：再点一次「扫描全部频道」→「重建媒体树」即可

### 第 3 步：Jellyfin 看片

1. 打开 **http://192.168.1.2:8097**，登录 `jellyfin / <密码见本地记录，不入库>`
2. 左侧 → 刷新媒体库（或等自动扫描），「TG频道」里出现剧集
3. 点开直接播放——**解码在本地完成**（服务器转码已禁用），拖进度条由 tgproxy 的 Range 缓存层支持，可随意快进

### 第 4 步：手机客户端

1. 应用商店装 **Jellyfin** 官方 App（iOS / Android）
2. 首次打开 → 「添加服务器」→ 地址填 `http://192.168.1.2:8097`
3. 登录 `jellyfin / <密码见本地记录，不入库>`
4. 同一 Wi-Fi 下即可直接播放、拖进度条

> iOS 建议在 App 设置里打开「原生播放器」以获得最佳直连效果。

## 日常使用

| 场景 | 操作 |
|------|------|
| 加新频道源 | 管理页添加 → 扫描 → 重建媒体树 |
| 频道更新了新剧集 | 扫描全部频道 → 重建媒体树 → Jellyfin 刷新库 |
| 想删掉某频道 | 频道列表点「删除」（其条目下次重建时移除） |
| tgproxy 重启 | `ssh lee@192.168.1.2` 后 `systemctl --user restart tgproxy`（一般无需，session 自动重连） |
| Jellyfin 管理后台 | http://192.168.1.2:8097/web/ 用管理员账号，控制台里可看活动播放 |

## 常见问题

**Q：播放卡顿或转不到集？**
先确认管理页状态是「Telegram 已连接」；再点「重建媒体树」后到 Jellyfin 刷新库。

**Q：拖进度条缓冲慢？**
tgproxy 对 Telegram 做了 chunk 缓存 + 预取优化，首次拖动到未缓存位置需拉取，二次拖回是秒开。缓存 512MB LRU，热门片段自动保留。

**Q：显示"unknown file; scan channels first"？**
流地址对应的条目还没扫描入库，先扫描频道再重建媒体树。

**Q： >2GB 的文件？**
当前暂不支持 Telegram CDN 重定向的大文件，遇到会报错；有需求可以后续加 CDN 分支。

**Q：外网能看吗？**
目前按局域网设计（strm 写的是 192.168.1.2）。服务器装了 Tailscale（100.97.45.52），要外网看的话告诉我，把 strm-base 换成 Tailscale IP 重刷媒体树即可。

**Q：安全提醒**
- `~/tgproxy/data/config.json` 里存着 Telegram session，等同账号钥匙，勿外传
- Jellyfin 管理员密码建议自己在 8097 后台改强一点

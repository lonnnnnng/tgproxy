# TGProxy Android v0.4.0

重新设计视频库、频道、我的和播放器界面，让浏览更紧凑，查找与播放更直接。

## 更新内容

- 视频库统一采用纯文字列表，展示文件名、频道、发布日期和文件大小，不再提供相册模式或展示模式设置。
- 新增视频详情页，显示完整文件名、来源、格式、完整发布时间，支持播放、续播和浏览同频道视频。
- 支持按发布时间或名称排序；首页显示最多两条继续观看记录，搜索与筛选保持固定。
- 移除三个 Tab 的大标题和副标题，压缩频道和设置行高，保留浅色、深色与跟随系统。
- 添加频道改用底部面板，扫描状态仅在运行时显示，结束后给出结果提示。
- 播放器顶部集中显示标题、来源和更多入口，底部保留锁定、倍速、比例及旋转；倍速和比例使用统一选择面板。
- 保留长按临时 2×、双击快进／后退、亮度／音量手势、后台播放和音轨／字幕选择。
- 修复迷你播放器在视频结束后无法重播，以及大字体搜索文字裁切等问题。

发布日期来自 Telegram 消息时间，按手机时区显示；没有有效时间的资源不显示日期。

## 下载与升级

安装 **`tgproxy-android-arm64.apk`**，要求 ARM64 手机、Android 8.0（API 26）及以上。

沿用正式版包名和签名，可直接覆盖升级，保留账号、频道索引及播放记录。请勿先卸载。

“TGProxy 验证”与正式版是两个独立应用，账号与数据不共享；只登录过验证版的设备，首次使用正式版时仍需登录。

## 开发者组件

同时提供 `player-controls-release.aar`。该组件接收 Media3 Player／MediaController，不依赖 Telegram 业务，支持独立接入其他 Android 项目。

AAR 不内嵌 Maven 依赖，接入方式见 [组件文档](https://github.com/lonnnnnng/tgproxy/blob/android-v0.4.0/android/player-controls/README.md)。

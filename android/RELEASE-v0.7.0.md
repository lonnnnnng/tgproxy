# TGProxy Android v0.7.0

下载恢复、续播、选片和另存更完整，大媒体库翻页与大字体使用更顺畅。保留紧凑文字列表。

## 更新内容

- 下载支持全部继续和失败批量重试，初始化／存储异常可重新恢复；坏记录逐条隔离，空间不足时暂停整批，断点写入保留存储余量。
- 同一账号和文档的在线／离线观看合并最近记录与续播位置；看完从头重播，换片不继承旧断点，退出账号后仍能保存离线进度。
- 视频分页采用排序值与主键游标，补充日期、名称及频道索引；下载列表每批50项，只刷新当前可见下载的进度。
- 新增上一条／下一条、同频道文字选片及默认关闭的连续播放；网络终止错误最多退避重试三次。修复后台切集后重绑旧视频，以及片尾切换本机来源的位置。
- 另存提供进度、取消、持久结果和分页历史；失败或中断可重新选择位置，未完成副本可以确认清理。修复通知取消后服务和唤醒锁未及时结束的边界。
- 点击区域至少48dp；窄屏／大字体下筛选、元数据和下载信息自然换行，播放器标题与时间不再受固定高度裁切。验证码与两步验证支持键盘“完成”。

POCO的10万条合成库深页游标查询约2.25ms，日期深OFFSET从48.59ms降至6.43ms；1000条下载历史的全量读取从11次降至6次。这是单机样本，不能作为下载速度提升或所有设备的时延承诺。

## 安装与数据

下载 **`tgproxy-android-arm64.apk`**，支持ARM64手机、Android 8.0（API26）及以上。版本0.7.0 / code8，沿用正式包名`dev.tgproxy.mobile`与原签名，可直接覆盖升级，保留账号、频道索引、观看记录和下载文件。**请勿先卸载。**

下载保存在App私有目录，卸载会删除；需要独立保留时，从完成条目的更多菜单另存副本。另存目标须能确认是空文件，已有内容或无法确认时提示重新选位置。进程中断后，下载恢复为暂停，另存记录保留并要求重新选保存位置。

“TGProxy 验证”和正式版是两个独立应用，账号和下载不共享。只登录过验证版的设备，首次使用正式版需要独立登录。

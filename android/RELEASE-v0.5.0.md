# TGProxy Android v0.5.0

频道更新更直接：顶部一键更新全部，频道行可单独更新。进度回到对应按钮和频道行，更新时不再挤动页面。

## 界面与频道更新

- 顶部更新按钮直接依次更新全部频道，不再弹出频道选择。
- 每个频道新增独立更新按钮，使用更小的 18dp 细线图标，保留方便点击的范围。
- 当前频道图标旋转，等待中的频道保持静止；进度、完成、失败和暂停显示在原有副文本中，移除顶部扫描卡片和重复进度条。
- 点击运行中的按钮可暂停整批任务；失败可在对应频道重试，其他频道继续更新。
- 首次更新只建立最新一页的索引，较早视频从“更多 → 扫描历史”补齐。后续更新同步新增内容，断点逐页保存。
- 移除首页“继续观看”区块，保留“最近播放”、保存进度和详情页续播。

## 播放、账号与索引修复

- Go 拉流复用文件引用刷新和数据中心迁移结果，合并并发恢复请求，减少重复请求。
- 完善相同视频暂停后的续播、播放失败重试和打开失败反馈，避免误播上一个视频。
- 修复删除频道后页码越界、退出账号后筛选残留及最近播放排序问题。
- 完善损坏授权恢复、两步验证超时后的重新登录和索引账号归属校验，保留索引重新授权时核实原账号。
- 频道菜单新增“校验已索引资源”，更新改名、换片和明确删除的条目；网络或权限错误不会据此删除本机数据。
- 优化频道查询和后台统计；“我的 → 运行诊断”可查看连接、下载速度、缓存与重试计数。

## 下载与升级

安装 **`tgproxy-android-arm64.apk`**，支持 ARM64 手机、Android 8.0（API 26）及以上。

沿用正式版包名和签名，可直接覆盖升级，保留账号、频道索引及播放记录。**请勿先卸载。** 数据库自动升级并保留旧数据。

“TGProxy 验证”和正式版是两个独立应用，账号与数据不共享；只登录过验证版的设备，首次使用正式版仍需登录。

同时附 `player-controls-release.aar`，本次播放器组件接口未变。AAR 不内嵌 Maven 依赖，接入方式见 [组件文档](https://github.com/lonnnnnng/tgproxy/blob/android-v0.5.0/android/player-controls/README.md)。APK 和 AAR 均附 SHA-256 校验文件。

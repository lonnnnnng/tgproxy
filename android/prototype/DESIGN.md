# 紧凑文字媒体库原型

本原型是已确认的 Android UI 方向：视频、频道、我的三个目的地，无页面大标题／副标题，固定搜索和筛选。浅深主题及色值与 [Android 设计](../DESIGN.md) 保持一致。

用户最终确认只保留文字列表，不做相册模式，不保留模式设置或封面占位。视频行约 55px，显示名称、频道、示例发布时间与大小；首页不显示“继续观看”，播放历史统一从“最近播放”查看。频道约 52px，设置约 49px；移除常驻“一切已就绪”。

详情提供完整文件名、来源、大小、发布时间、续播和同频道资源。播放器保留静态示例画面，用于模拟横竖屏、倍速、比例、锁定、双击及亮度音量，不代表已取得 Telegram 视频封面。

频道顶部更新全部，每行有单频道更新按钮。18px 小图形独立于点击范围，串行队列只让当前频道和顶部图形旋转；原副文本展示等待、更新、完成或暂停，不增加顶部状态区。点运行中的按钮暂停示例任务。

所有数据均为演示数据；真实 Android 发布时间来自索引中的 Telegram 消息 Unix 秒。原型日期不参与真实数据验证。主题和倍速可保存在浏览器；展示模式偏好不再读写。

# TGProxy 视频库 HTML 原型

这份原型展示已确认的紧凑文字列表方案，不连接 Telegram，不读取真实账号或频道数据。原生实现见 [Android README](../README.md)。

在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1` 后访问 `http://127.0.0.1:4173`，也可直接打开 `index.html`。无需安装依赖。

- 视频：固定搜索和筛选、继续观看、纯文字列表、示例发布时间、排序和详情。
- 频道：紧凑频道行、添加、模拟同步和确认移除，无常驻就绪卡片。
- 我的：紧凑设置行、浅深色、默认倍速与手势说明。
- 播放：静态示例画面、模拟时间轴、倍速、比例、锁定、横竖屏和手势反馈。

已取消相册模式及其设置，列表、详情和迷你播放器不显示封面。播放器中的图片仅作为画面示意，来源见 [assets/SOURCES.md](assets/SOURCES.md)。主题和倍率存于浏览器，示例资源刷新后恢复。

PC 左栏和顶部工具仅用于评审，不进入 App。窄屏展示手机布局，支持 Tab、Escape、空格及左右方向键。浏览器验证只说明原型交互，不等同于 Android 真机、视频解码或 Telegram 网络验证。

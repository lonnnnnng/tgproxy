# TGProxy Android

TGProxy Android 在 ARM64 手机上使用 Telegram 用户账号索引所选频道的视频，并通过本机 Range 服务和 Media3 播放。手机直接访问 Telegram，不依赖 Linux TGProxy 服务、Jellyfin 或媒体树。

用户使用手机号、验证码和可选两步验证密码授权。API ID/Hash 可选：两项留空时使用项目预设值，填写时必须成对提供；凭证和登录会话通过 Android Keystore 加密后保存，并排除系统备份。视频索引及游标存入应用私有 SQLite。内置 Go 核心只监听回环地址，媒体访问需随机令牌。

可从 Telegram 已加入频道中选择，或通过公开链接/ID 添加多个频道。扫描按原始 Telegram 消息 ID 分页，在每页事务中同时保存视频和游标；用户可恢复旧消息扫描或独立同步新增内容。一个频道的失败或取消不会覆盖其他频道或已提交页面。

视频库支持跨频道搜索、频道筛选、分页和最近播放。MediaSessionService 在播放器页面退出后维持当前播放，系统通知提供媒体控制，进度定期保存；另提供明确标注的本地测试片。

下载支持串行后台任务、断点恢复、全部继续和失败批量重试；空间不足时暂停整批，为进度与数据库保留写入余量。完成文件独立保留，退出账号后仍可离线观看。同一账号和 document 的在线／离线观看按最新时间续播，并同步最近播放；看完归零，换片不继承旧断点。

播放器支持同频道排序／搜索范围内的上一条、下一条及分页文字选片。下载管理中的选片只包含本机文件。连续播放默认关闭，开启后在片尾播放下一条；网络终止错误最多退避恢复三次，权限、换片和解码错误提供人工恢复入口。

已完成视频通过系统文件选择器另存，前台服务负责进度、取消和持久结果。中断后重新选择保存位置，未完成副本由用户确认后清理。界面保持紧凑文字列表，交互区域至少48dp，大字体和窄窗口允许筛选、元数据及控件自然增长。上述优化纳入Android 0.7.0。

Android 0.7.0 面向ARM64手机。Debug包沿用`.poc` application ID以原地升级并保留验证数据；Release使用稳定application ID `dev.tgproxy.mobile`，正式版覆盖升级保留原数据，首次从验证版转入正式版需要独立登录。版本发布复用同一签名密钥；公开分发前应在Telegram官方`my.telegram.org`申请自己的API ID/Hash；项目预设值只适合私下验证，不作为公开发行凭证。
